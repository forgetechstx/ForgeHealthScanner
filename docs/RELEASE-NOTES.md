ForgeHealthScanner 1.6.0 by Forge Technologies. **Unsigned**.

- Open **Scan history** from the portable dashboard and compare two saved scans. The comparison highlights new warnings and warnings resolved by a passing check. Missing and unreadable checks remain separate.
- The startup splash displays the Forge Technologies logo and version. Progress, Cancel and opt-in history remain available.
- The collector distinguishes incomplete update checks from passing checks and reuses recent event-log coverage lookups within a scan. A local history write failure leaves the completed report available.

Verify the ZIP against SHA256SUMS.txt, extract it, and run HealthScan.exe on Windows 10 or 11. The release includes a build manifest and CycloneDX SBOM.
