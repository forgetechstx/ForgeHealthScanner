ForgeHealthScanner 2.0.1 is an unsigned portable Windows desktop application by Forge Technologies.

- Use **Remove a program** to open Windows Installed apps and select an uninstaller.
- Review native scan results, print reports, compare saved scans, and inspect or delete registry backups. Local history is opt-in per scan.
- Startup cleanup preserves existing executable aliases and validates the exact command during recovery.
- Firewall, Defender, storage and battery checks now distinguish incomplete evidence. History flags ambiguous changes for review.
- The portable EXE contains the native C# app and needs no PowerShell session, browser or installer.

Download the ZIP and compare its SHA-256 with SHA256SUMS.txt. The accompanying build manifest and CycloneDX SBOM identify the tested executable.
