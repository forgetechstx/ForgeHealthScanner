Your next health check.

The easiest way: double-click Open-HealthScan.cmd in the app folder. It collects status and opens your report in a private browser window.

To keep a report history, run this in Windows PowerShell from the app folder:

.\Open-HealthScan.cmd -SaveReport

Or run the collector by hand from the app folder, then import the JSON saved to your Desktop. Windows blocks scripts by default, so start it like this (the setting lasts for this run only):

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Collect-Health.ps1

For an optional Microsoft Defender quick scan, open PowerShell as administrator. It starts in a different folder, so first go to the app folder (cd followed by the folder’s full path), then run:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Collect-Health.ps1 -QuickScan

Run HealthScan.exe again to collect a new snapshot. The results open in your default browser, with no report saved by the tool.

Your report is only in this browser tab. Reloading the page will not bring it back, so use Export JSON to keep it, or Import report to revisit a copy you saved.

Run Defender quick scan starts a new elevated scan. The button works for up to 30 minutes after HealthScan.exe starts.

For an optional Defender quick scan, run this from an administrator Command Prompt:

HealthScan.exe -QuickScan

Windows Update results use this computer’s cached information. Some checks need administrator access. The optional Defender scan may take several minutes. If script execution is blocked, follow your organization’s approved process.
