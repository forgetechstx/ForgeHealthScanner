A clearer picture of your Windows PC.

ForgeHealthScanner reads local computer-health status and displays results in a native Windows desktop app. A portable Windows 10/11 utility with progress, cancellation and optional local history.

Version 2.0.1 — unsigned. Windows may show an unknown-publisher warning. SignPath has not accepted or sponsored this project.

Download portable ZIP · 2.0.1

SHA-256 checksums · CycloneDX SBOM · Build manifest · Release notes

Review status, then choose your next step

  • Storage space, drive condition, battery capacity and selected stability events.
  • Windows Update cache, protection/configuration status and startup inventory.
  • A current-step progress window with Cancel. History is off by default per scan.
  • Open Windows Installed apps with Remove a program. Monitor a Defender quick scan, print results or review startup cleanup and recovery backups.

No installer, service, startup task, remote port scan or application telemetry. Windows provides the .NET Framework runtime. Optional system modules may be unavailable. This is computer-health software, not a medical app or a security guarantee.

Verify and run

Download the ZIP and SHA256SUMS.txt. In PowerShell, run Get-FileHash .\ForgeHealthScanner-2.0.1-portable-unsigned.zip -Algorithm SHA256 and compare the full value. Extract the ZIP and run HealthScan.exe. Review the privacy policy before saving or sharing reports.

Keep the EXE in your chosen folder. A desktop shortcut may point to it and use its embedded icon. To remove the app, delete the EXE and shortcut; retain or separately review local history and recovery backups.

Privacy and code signing policy

The app does not upload reports to Forge Technologies. Local reports, exports and optional startup backups can contain private computer details. Read the privacy policy.
