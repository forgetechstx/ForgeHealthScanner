Privacy policy

Reports and local storage

ForgeHealthScanner 2.0.1 reads local Windows health status. Reports include the PC name, OS build, time, hardware details, hashed battery identifiers when available, antivirus names, status and event counts. Reports can identify a PC.

Scans stay in memory unless you select local history, export JSON or print. Each scan starts with history off. Saved scans use %LOCALAPPDATA%\HealthScan\scan-history. Your printer, shared folders or sync software may transfer copies.

Optional actions

Startup cleanup saves a whole current-user Run key backup and a recovery journal in %LOCALAPPDATA%\HealthScan\registry-backups. These files can contain private commands, paths and the account SID. Review backups before sharing. Files remain until you remove them.

Remove a program opens Windows Installed apps. Windows and the selected uninstaller control removal. Defender follows your Windows settings. Update searches use the local cache. ForgeHealthScanner has no project telemetry or report upload endpoint.

Website and support

GitHub hosts this website and release downloads and processes access data. Public issues are visible to others. Review and redact any information before sharing it.
